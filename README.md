# Climb2Cal



Welcome to climb2cal

This is a script i have written to sync my schedule from the reach with my google calendar

its simple enough that there shouldn't bee may or any issues



## HOW TO USE:



### If you havent used it before:



double click 'setup'

this will get all dependancies installed



you will then be prompted to enter your first and last name

(this will be used to log into the reach's website, so use the same name as you do there)



then you will be prompted to connect your google account

you will get a warning that says the app has not been authenticated by google

this is expected, you can hit continue

and that's it, the script will add everything to a secondary calendar in your google account 



### if you have used this before:



every time you want to run the program again just double click 'Climb2Cal' 

it will also make any changes (such as cancelled sessions, or start/end timings)

as well as adding any new sessions





## \##TROUBLESHOOTING##



\-if you have entered your name incorrectly, please delete the 'login.json' file

\-and if you wish to use a different google account please delete the "token.json" file

in both cases, run the script again :)



any issues just shoot me a message or find me at the reach, i'm more then happy to help
